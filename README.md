# FDE MVP · 实习管理与教学改进（知行职业学院 · 机电试点）

技术方案（《05-技术方案.md》）选定最小闭环「**变更同步 + 事实归集 + 建议草稿**」的可运行 MVP，5 条要求对应实现如下：

| 要求 | 实现 |
| --- | --- |
| ① FastAPI | `main.py` 单体后端（接入→映射→规则→模型→复核台→输出 + 审计旁路），SQLite 存储，监听 `$PORT` |
| ② Harness | `harness.py` 测试台，16 项检查：鉴权 401、跨企业越权留痕(E7)、成绩写回拒绝、错发检测(E1)、改派幂等(E5)、证据不足退回(E2)、低置信转人工、N2 三要素、口径备案(E3)、审计只追加、RAG 检索命中；管理端一键运行 |
| ③ 知识库 | Wiki 知识页（口径注册表/任务清单/制度条款/企业档案/停止条件）+ 36 条访谈事实（教育-001~036）+ 纯 Python RAG 检索（bigram 重叠打分）+ LLM 层（默认离线抽取器，`LLM_PROVIDER=openai` 可切换在线 API） |
| ④ 权限 | SaaS 管理员（admin：用户/口径/审计全量）+ 分层用户（教务/教师/企业导师/风险），数据域按企业过滤（§5.4 权限矩阵代码化），越权拒绝并留痕 |
| ⑤ 上线部署 | 单端口 HTTP 服务，发布为在线应用（workbuddy_sites_deploy），输出分享链接 |

## 核心流程（最小闭环）

1. **反馈归集**：企业导师提交双周评语（≤5 项表单）→ 抽取器生成「任务—行为—建议」三元组，附原文区间与置信度；
2. **变更同步**：换岗未办结 → 待办挂起（N3 具名承接人改派，同键幂等拒绝，E5）；错发 = 0 硬指标；
3. **建议复核**：置信度 <0.6 停人工队列（停止条件写进代码，教育-032）；N2 三要素齐备才可签核入库；缺要素永远存草稿；
4. **审计旁路**：只追加，无 UPDATE/DELETE 接口，可重建当次处理；
5. **成绩写回**：接口不存在，任何调用 403 + 留痕（ZL-01 第十七条）。
